## 调研方法

1. 以 arXiv 为主要来源，按提交日期检索 2025–2026 论文；
2. 官方博客（World Labs、NVIDIA、Wayve）用于产品/系统细节；
3. 每篇关键工作写结构化笔记（结论、方法、结果、局限、启示）；
4. 区分事实（A/B）与待核实（C），集中登记；
5. 结论沉淀到全景/路线/评测文档，不在笔记里堆长文。

## 更新节奏

- 每月检查一次 arXiv 新论文与厂商发布；
- 每季度重审一次系统对比矩阵；
- 超过 6 个月的系统对比表标记“历史快照”；
- 发现结论变化时，先更新 catalog/notes，再改全景文档。
