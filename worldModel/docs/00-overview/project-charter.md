# 项目章程

- **项目名**：World Model Research & Build
- **版本**：v0.1
- **日期**：2026-11-17
- **状态**：draft（待评审）

## 1. 使命

研究与构建一个**可验证、可编辑、可交互**的世界模型系统，并先在叙事/短剧场景落地。

## 2. 为什么做

- 世界模型是 2025–2026 年 AI 的核心方向之一，但从“视频生成”到“可行动的世界模拟”仍有巨大 gap。
- 现有系统在状态跟踪、长时记忆、可编辑性、验证上系统性不足（FlipTest、Prediction or Persistence 等）。
- 我们已有短剧内容管线与结构化 canon，具备做“叙事世界模型”的独特数据优势。
- 不做基础模型军备竞赛，做状态层、验证层与领域应用，是小团队更可行的差异化。

## 3. 范围

### 做

- 世界状态表示（实体、关系、事件、canon、不确定性）；
- 动作条件动力学（物理/语义/编辑三类动作）；
- 运行时验证与修复；
- 可插拔渲染器（视频/3D/引擎）；
- 评测 harness（状态、反事实、长时程、叙事）；
- 首个垂直：交互式叙事/短剧。

### 不做（至少第一阶段）

- 从头训练通用视频基础模型；
- 通用机器人操作/自动驾驶的完整栈；
- 照片级全身多智能体物理；
- 测绘级 3D 重建；
- 无人类在环的全自动长剧生成。

## 4. 原则

1. **状态优先于像素**：先证明状态正确，再谈画质。
2. **验证是一等公民**：运行时检查，不是离线装饰。
3. **复用优先**：用开源/商用骨干，自研集中在差异化层。
4. **可证伪**：每个阶段有明确假设、指标、通过/否决标准。
5. **垂直优先**：先把叙事跑通，再谈跨域。
6. **合规先行**：数据/肖像/版权/水印从第一天记录。
7. **文档即资产**：调研、决策、实验都可追溯。

## 5. 成功标准

### 12 个月

- 可演示的跨 10 集交互式叙事世界；
- 开源评测 harness（状态/反事实/长时程）；
- 2 篇论文/技术报告；
- 与现有短剧管线集成，成本可接受。

### 24 个月

- 多季/多项目规模化；
- 决定是否扩展到机器人/游戏/教育；
- 形成可持续的团队与资源。

## 6. 关键约束

| 约束 | 说明 |
| --- | --- |
| 算力 | 8–32 张 H100 量级；推理成本是主要瓶颈 |
| 数据 | 依赖现有短剧资产 + 公开视频 + 仿真；动作/标注稀缺 |
| 时间 | 12 个月到可演示；每 6–8 周决策门 |
| 团队 | 最小 5–6 人；可先兼职 |
| 合规 | 肖像、剧本版权、生成内容溯源 |

## 7. 干系人

| 角色 | 关注点 |
| --- | --- |
| 研究团队 | 技术可行性、论文、评测 |
| 工程团队 | 可实现的架构、成本、稳定性 |
| 内容/编剧 | 创作效率、可控性、一致性 |
| 产品/业务 | 成本、差异化、上市时间 |
| 法务/合规 | 版权、肖像、数据许可 |
| 管理层 | 里程碑、资源、风险 |

## 8. 治理

- **决策门**：每阶段结束 go/no-go，输出 ADR。
- **评审**：方案/架构/评测计划至少一次跨职能评审。
- **文档**：调研/设计/实验/决策全部入库，索引自动生成。
- **复盘**：每阶段结束做“什么有效/什么无效/下一步”。
