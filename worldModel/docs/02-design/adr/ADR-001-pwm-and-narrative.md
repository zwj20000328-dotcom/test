# ADR-001: 以 PWM 为方向、以叙事/短剧为首个垂直

- **日期**：2026-11-17
- **状态**：proposed（待评审）
- **决策者**：项目组
- **关联**：[PWM 方案](../01-proposal.md) · [路线图](../05-roadmap.md)

## 背景

调研显示：

- 视频世界模型在状态跟踪上系统性失败（FlipTest：11 个模型，最佳 18.3%）；
- 显式持久状态正在回归（Physical Registry、GameWM、Atlas spatial context）；
- 机器人 WAM 已是红海（Cosmos 3、GE-Act、GreenWAM 等），需要大量动作数据与算力；
- 叙事/短剧场景的状态结构化程度高、物理精度要求适中、长时程一致性是核心痛点，且团队已有内容管线与 canon 资产。

## 选项

### A. 通用视频世界模型

从头训练/微调一个通用视频生成模型，追求画质与开放域。

- 优点：市场大、演示直观。
- 缺点：资本/数据门槛极高；与 Cosmos/Atlas/Sora 正面竞争；状态/可验证性弱。

### B. 机器人 WAM

做面向操作的世界-动作模型。

- 优点：学术热、评测明确、产业需求强。
- 缺点：动作数据昂贵；硬件/仿真门槛；与 NVIDIA/智元/上海 AI Lab 等强队正面竞争。

### C. 持久世界模型（PWM）+ 叙事垂直

把状态层/验证层作为差异化，首个垂直做交互式叙事。

- 优点：数据结构化、可利用现有资产、评测可做、长时程一致性是真实痛点、与基础模型互补。
- 缺点：叙事质量评估主观；商业规模待验证；渲染成本。

## 决定

提议选择 **C**：

1. 技术方向：PWM（显式持久状态 + System-1 动力学 + System-2 验证 + 可插拔渲染）；
2. 首个垂直：交互式叙事/短剧；
3. 不自研通用视频基础模型，使用开源/商用骨干；
4. 评测先行，Phase 1 以状态/反事实指标为验收。

## 理由

- 与团队现有优势（短剧管线、canon、剧本资产）匹配；
- 避开与基础模型厂商的正面竞争，做它们不擅长的状态/验证/叙事层；
- 叙事对物理精度要求较低，能先用结构化状态跑通闭环；
- 评测可结合规则 + 人类评估，能形成可复现的验收标准；
- 若成功，接口可复用到游戏/教育/机器人。

## 影响

- 需要新增：状态服务、验证器、canon schema、叙事评测集；
- 渲染仍依赖外部模型，成本与供应风险需管理；
- 团队需要编剧/叙事顾问参与；
- 论文方向偏“状态表示 + 验证闭环 + 叙事世界模型”，而非“更大视频模型”。

## 复审时间

Phase 1 决策门（2027-03）复审：若 H1（显式状态带来一致性提升）不成立，考虑转向“视频 + 记忆”或评测工具方向。
