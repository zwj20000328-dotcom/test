# 架构决策记录（ADR）

本目录记录影响项目方向的技术/产品决策。每个决策一个文件，命名 `ADR-<NNN>-<slug>.md`。

## 什么时候写 ADR

- 选择/放弃一条技术路线；
- 确定首个垂直场景；
- 选定骨干模型/渲染器/存储方案；
- 改变评测标准或阶段门；
- 任何“以后会有人问为什么这么选”的决定。

## 模板

```markdown
# ADR-00X: <决策>

- 日期：
- 状态：proposed / accepted / superseded / rejected
- 决策者：
- 关联：

## 背景

## 选项

## 决定

## 理由

## 影响

## 复审时间
```

## 规则

- 决策一旦 accepted，不删除；被替代时标 `superseded` 并链接新 ADR。
- 决策必须写“为什么不是另一个选项”。
- 与调研/设计文档交叉链接，避免孤立。
