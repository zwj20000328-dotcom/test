# 实验记录

本目录存放每次训练/评测的实验报告，按 `YYYY-MM-DD-<topic>.md` 命名，不覆盖历史。

## 报告模板

```markdown
# 实验 <id>: <主题>

- 日期：
- 代码 commit：
- 数据版本：
- 模型版本：
- 渲染器版本：
- canon 版本：
- 负责人：

## 目标假设

## 变更

（相对上一个基线改了什么。）

## 测试集

（套件/场景/划分/样本量。）

## 结果

| 指标 | 本次 | 基线 | 配对差值 | 95% CI |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

## 失败分析

（按类型统计，附代表样本。）

## 回归测试

（旧能力是否退化。）

## 结论

支持 / 否定 / 不确定 + 一句话解释。

## 下一步
```

## 规则

- 每个实验必须能由 commit + 数据版本复现；
- 报告必须包含失败案例，不只报平均分；
- 与 [评估计划](../04-evaluation-plan.md) 的套件编号对应；
- 结论变化时更新 `01-research/` 或 `02-design/`，不要只留在实验报告里。
