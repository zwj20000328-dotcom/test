# PWM 评估计划

- **状态**：draft
- **版本**：v0.1
- **日期**：2026-11-17
- **关联**：[调研-评测](../01-research/04-evaluation.md) · [方案](01-proposal.md)

## 1. 原则

1. **状态优先**：先证明状态正确，再讨论画质。
2. **配对比较**：同一初始状态、同一动作，比较不同模型；不只报绝对值。
3. **持续控制**：所有预测指标都要配 persistence 对照。
4. **多层报告**：均值 + 置信区间 + 失败类型分布。
5. **回归测试**：模型/预处理/渲染器版本变化都要重跑固定套件。
6. **下游效用**：最终以真实任务/人类任务完成情况为准。

## 2. 测试套件

### S1 物理与状态基础

| 项 | 内容 |
| --- | --- |
| 场景 | 合成刚体、关节、简单形变；Unity/MuJoCo/Isaac |
| 任务 | 推、落、堆叠、碰撞、遮挡 |
| 指标 | PVR（物理违规率）、FSA（状态翻转准确率）、DCD（动力学距离） |
| 门槛 | PVR < 5/100 帧；FSA > 70%（随机 50%） |
| 基线 | persistence、开源视频模型、V-JEPA/DINO-WM |

### S2 持久与重访

| 项 | 内容 |
| --- | --- |
| 场景 | 单场景多房间、真实视频扫描 |
| 任务 | 离开→改变→返回；遮挡→解除；撤销动作 |
| 指标 | IDR（身份保持）、SRR（场景重写率）、记忆半衰期 |
| 门槛 | 10 次重访 IDR > 85%；SRR < 10% |
| 变体 | 有效时间记忆开/关；3D 记忆开/关 |

### S3 动作与反事实

| 项 | 内容 |
| --- | --- |
| 场景 | 合成 + 叙事片段 |
| 任务 | 同一状态施加不同动作；最小对干预 |
| 指标 | AS（动作敏感度）、CFR（反事实正确率）、IR（干预响应） |
| 门槛 | AS 显著高于无条件（p<0.05）；CFR > 65% |
| 变体 | 动作 dropout、动作敏感度损失开/关 |

### S4 长时程

| 项 | 内容 |
| --- | --- |
| 场景 | 10–30 分钟连续交互 |
| 任务 | 多事件、多场景、回访、分支 |
| 指标 | 漂移曲线、矛盾率、记忆检索准确率 |
| 门槛 | 30 分钟内 hard 矛盾 < 3 个；漂移增长斜率低于基线 50% |
| 变体 | 有无验证器；有无 checkpoint |

### S5 叙事垂直

| 项 | 内容 |
| --- | --- |
| 场景 | 现有短剧资产，跨 10 集 |
| 任务 | 跨集生成、角色一致性、what-if、retcon |
| 指标 | canon 矛盾率、身份保持、人类偏好、任务时间 |
| 门槛 | 矛盾率 < 5%；身份 > 90%；偏好胜率 > 60% |
| 基线 | 现有管线、纯视频模型 + 长 prompt |

**Canon 矛盾分类**：

| 类型 | 例子 | 严重度 |
| --- | --- | --- |
| 事实矛盾 | 角色已死又出现 | hard |
| 知识矛盾 | 角色知道自己未经历的事 | hard |
| 关系矛盾 | 姐妹关系变成陌生人 | hard |
| 时间线矛盾 | 事件顺序错乱 | hard |
| 外观矛盾 | 发色/服装/年龄突变 | soft |
| 语气/风格矛盾 | 角色说话方式突变 | soft |
| 世界观规则矛盾 | 现实题材出现魔法 | hard |

### S6 效率

| 指标 | 目标 |
| --- | --- |
| 交互延迟 | 首版 < 200 ms/帧；目标 < 66 ms |
| 吞吐 | 并发世界数/GPU |
| 显存 | 单世界 < 预算 |
| 成本 | 元/分钟内容 |
| 缓存命中率 | > 40%（交互场景） |

### S7 回归与鲁棒性

| 项 | 内容 |
| --- | --- |
| 配置矩阵 | 4 种预处理/渲染器/模型版本组合 |
| 指标 | 结论一致性、负向翻转率、harness 故障检出 |
| 门槛 | 4 种配置结论一致率 > 90% |
| 参考 | TetraState 思路 |

## 3. 协议

### 3.1 运行

```text
for seed in [0,1,2]:
  for scenario in test_set:
    reset(scenario.initial_state)
    for t in actions:
      pred = model.step(action)
      record(pred, oracle.state)
    compute metrics
report mean, 95% CI, per-type failure counts
```

### 3.2 划分

- 训练/验证/测试按**场景、角色组合、剧集**划分，不按帧随机划分。
- 测试集包含：
  - 未见物体组合；
  - 未见场景布局；
  - 未见因果链；
  - 长尾动作。
- 定期做“污染检查”：测试集是否出现在训练数据中。

### 3.3 配对比较

对每个测试样本，同时运行：

1. 目标模型；
2. persistence 对照（不调用预测器）；
3. 至少一个强基线。

报告**配对差值**与置信区间，而不只是目标模型绝对值。

## 4. 人类评估

### 4.1 叙事场景 rubric

| 维度 | 问题 | 1–5 分 |
| --- | --- | --- |
| 角色一致性 | 外观、性格、说话方式是否一致 |  |
| canon 一致性 | 是否违反已设定事实/规则 |  |
| 空间连续性 | 走位、场景、道具是否连贯 |  |
| 因果合理性 | 事件是否有合理因果 |  |
| 镜头/风格 | 是否符合剧集风格 |  |
| 可用性 | 是否可直接用于剪辑/还需修改 |  |

### 4.2 样本量与设计

- 每个对比至少 30 个片段 × 3 位评审；或 100 对 A/B 偏好。
- 评审盲测：不告知模型来源。
- 计算 inter-rater agreement（Krippendorff's α）；α < 0.6 时增加培训/样本。
- 记录评审理由，不只分数。

### 4.3 任务时间

让编剧完成指定任务（如“生成第 2 集某场戏并保持 canon”），记录：

- 完成时间；
- 修改次数；
- 最终可用率；
- 主观负担（NASA-TLX）。

## 5. 阶段门

| 阶段 | 必须通过 | 可以放宽 |
| --- | --- | --- |
| Phase 1 | S1 PVR/FSA、S2 IDR、S7 一致性 | 画质、实时性 |
| Phase 2 | S3 CFR、S5 矛盾率/偏好、S6 延迟 < 500ms | 长时程 30 分钟 |
| Phase 3 | S4 30 分钟、S6 15 fps、S7 回归 | 多季 canon |
| Phase 4 | 成本、规模、跨域 | — |

未通过时的处理：

1. 缩小范围（场景/时长/指标）；
2. 回退到上一稳定版本；
3. 换技术路线（如视频→结构化）；
4. 停止该方向，保留评测与数据资产。

## 7. 反作弊与有效性

- **动作敏感度检查**：如果模型对不同动作输出几乎相同，判为无效。
- **持续性检查**：如果模型不如复制上一帧，判为无效。
- **分布外检查**：至少 20% 测试样本来自未见组合。
- **人工抽检**：自动指标高的样本人工复核，防止指标 gaming。
- **对抗测试**：专门构造规则漏洞/边界条件，测试 verifier 是否被钻空子。
- **版本回归**：任何提升都要检查旧能力是否退化。

## 8. 工具与数据格式

统一模型接口：

```python
class WorldModelAdapter:
    def reset(self, world_state): ...
    def step(self, action) -> StepResult: ...
    def render(self, camera) -> Observation: ...
    def state(self) -> WorldState: ...
```

`StepResult` 至少包含：状态、观测（可选）、不确定性、延迟、矛盾。

评测输出 JSON：

```json
{
  "run_id": "pwm-v0.3-s1-20270115",
  "model": "pwm-dyn-v0.3",
  "suite": "S1",
  "metrics": {

    "FSA": {"mean": 0.74, "ci95": [0.70, 0.78]}
  },
  "paired_delta_vs_persistence": {"FSA": 0.21},
  "failures": {"penetration": 12, "identity": 3}
}
```
