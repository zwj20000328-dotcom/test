## 一句话

**PWM** 把世界状态从视频生成模型中解耦，做成显式、可版本化、可分支的状态图；System-1 快速预测，System-2 验证/修复/规划，渲染器可插拔。首个垂直是交互式叙事/短剧。

## 评审要点

评审时请重点挑战：

1. “显式状态 + 验证”是否真的比“更大视频模型 + 记忆”更有效？
2. 叙事动作的离散化是否可行？会不会丢失表演细节？
3. 渲染器可插拔是否导致系统过于复杂？
4. 评测指标是否能区分“真预测”与“复制/平均”？
5. 成本是否能降到业务可接受？
6. 与 Cosmos/Atlas 等基础模型的关系：集成还是竞争？

## 变更流程

- 方案 v0.x：draft，允许大改；
- 评审通过后 v1.0：approved，变更需 ADR；
- 被替代时标 `superseded`，保留历史。
