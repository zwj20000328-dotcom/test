# 06 · 评审与修订记录

> 本报告采用"生成 → 独立评审 → 对抗性复核 → 修订"的流程。本文件记录评审方法、主要修正与仍存在的局限，供读者判断报告的可信度。

---

## 1. 评审方法

**四位独立评审者**（互不共享上下文）：

| 评审者 | 职责 | 关注点 |
|---|---|---|
| 事实核查 | 对照 arXiv 摘要核对 03/01 中带数字或强断言的陈述 | 数字是否张冠李戴、结论是否过度外推 |
| 新颖性审查 | 对照 2025–2026 最新工作审查 04 的 P1–P10 | 是否已被做过、目标是否可测、是否可行 |
| 一致性审查 | 通读全部文档 | 数字/术语/编号/交叉引用是否矛盾 |
| 完备性批判 | 找出报告遗漏的方向、玩家、论文、反例 | "这份报告漏掉了什么" |

**对抗性复核**：每条 high/medium finding 由一名独立复核者尝试**反驳**。只有读原始材料后仍成立的，才判 `confirmed`；部分成立判 `partially`；被推翻判 `refuted`。

**结果**：62 条 finding；30 条进入复核 → **13 confirmed / 16 partially / 1 refuted / 29 confirmed（总）**。完整清单见 `raw/review-summary.md`。

## 4. 仍存在的局限

1. **评审也是模型**：评审者与作者共享同一知识边界，可能同时漏掉同一类错误；只有回到原始论文才能最终确认。
2. **摘要级证据**：多数核对只到摘要（900 字符），未读全文；摘要未报告的数字一律写"摘要未给出"。
3. **会议/年份未用 DBLP 逐一核实**：arXiv 元数据不含录用信息。
4. **工业数字**：厂商口径无法独立复现；报告只做"官方口径"标注。
5. **中文/非 arXiv 文献**：CNKI 不可访问，国内期刊与部分顶会（无 arXiv 版本）覆盖不足。
6. **2026-10-30 之后**：未覆盖。
