## 一分钟结论

存储已经是大模型系统的**第一性约束**，但行业对它的理解仍停留在"容量不够就 offload"。2025–2026 年的真实进展表明，瓶颈已经转移到三个更棘手的问题：

1. **搬得动吗**——决定 TTFT 的是"对象数"而不是"字节数"（同样 6 GiB，192 个对象 2.1 s，6,144 个对象 3.0 s）；
2. **搬得对吗**——非前缀复用的朴素拼接只能保留 **37.8%–47.2%** 的全量 prefill 答案，修复后可回到 98%–99.8%；
3. **搬得起吗**——KV 写入量可在数月内耗尽 SSD 寿命；远端命中 0.88 s 可能比重算 0.31 s 更慢。

**最值得下注的三个方向**：KV 对象存储与复用契约、寿命感知的写入门控、KV 存储基准。

## 五个关键数字

| 事实 | 数字 | 含义 |
|---|---|---|
| KV 体积 | 70B/128K/batch32 ≈ **1.25 TiB** | 超过多数单机内存，必须分层 |
| Decode 算术强度 | GQA-8/FP16 = **8 FLOP/B** | 比 H100 拐点 295 低 37×，物理上带宽受限 |
| Prefill vs Decode | 相差 **3–4 个数量级** | PD 分离不是偏好，是物理必然 |
| Checkpoint | **16 B/param**，峰均比 **77×** | 671B ≈ 10.7 TB；按平均带宽规划会低估两个数量级 |
| LLM 训练数据流 | **12–50 MB/s**（1024 GPU） | 训练侧存储主角是 checkpoint 与元数据，不是数据加载 |

## 十大发现（详见 `03`）

1. **对象粒度决定 TTFT**，不是字节数；每一层（查找/分配/提交/送 GPU/写回/索引）都按对象计费。
2. **"远端命中一定更快"失效**：远端命中 0.88 s vs 重算 0.31 s，p99 从 3.96 s 涨到 17.3 s。
3. **SSD 寿命成为一等约束**：KV 写入量超容量，寿命从数年缩短到数月。
4. **复用的核心是正确性**，不是命中率；存在"可容忍集"，几何相似度不能预测可用性。
5. **CXL 不是万能解**：现货 CXL-SSD 比 DRAM 慢 3×、不比 NVMe 快；价值在容量/共享。
6. **GPU 开始直控 I/O**，但"对象粒度税"仍在。
7. **混合/线性注意力让前缀缓存抽象失效**：状态无法回滚到任意前缀。
8. **Checkpoint 正从"文件"变成"可重分片数据集"**，并出现零 I/O 恢复；异步不等于免费（+656.7% 延迟）。
9. **Agent 记忆是 R0 数据，却被当缓存设计**：缺事务、版本、删除传播、隔离。
10. **缓存已成为安全边界**：侧信道攻击成功率可达 100%，七家 API 提供商检出跨用户共享。

> 元发现：**评测缺失**导致收益不可比——14 种驱逐算法相对 LRU 提升有限；压缩组合在该单设备短上下文实验中未叠加；checkpoint 机制"没有普适最优"。

## 方法（为什么这份报告可信）

1. **真实检索，不靠记忆**：客户端搜索被策略拦截后，改用 `curl` 直接调用 arXiv 官方 API，47 组查询、1,878 篇去重；所有综述只允许引用抓取集合中真实存在的条目。
2. **引用可核验**：529 个 `[arXiv:ID]` 逐一比对，缺失 0；完整清单见 `05a`。
3. **定量而非形容词**：容量/带宽/成本/checkpoint/数据供给均给出公式、假设与算例（`raw/analysis-quant.md`）。
4. **交叉复核**：15 个方向由独立 agent 撰写；另有一轮"文献计量 + 技术主张"双视角核验。
5. **明确标注不确定**：会议/年份属 B/C 级证据；厂商数字标注口径；摘要截断处写"摘要未给出"。

## 局限

- 以 arXiv 为主，无 arXiv 版本的经典（Orca、DiskANN、3FS 论文）与国内期刊覆盖不足；H2O 已核实为 [arXiv:2306.14048](https://arxiv.org/abs/2306.14048)。
- 检索截止 **2026-10-30**；
- 会议录用信息未逐一用 DBLP 核实；
- 工业数字口径不一，跨厂商不可直接比较；
- 定量模型是一阶近似，用于数量级论证。
