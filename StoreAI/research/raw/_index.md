# 原始调研产物索引

本目录存放多智能体文献调研的结构化结果（JSON）。

证据等级约定：
- A：本人高置信度（标题/团队/核心机制确定，可能记得会议与年份）
- B：中置信度（机制确定，会议/年份可能有偏差）
- C：低置信度（仅记得大致思路，引用细节需核实）

环境说明（2026-11-02 更新）：客户端 WebSearch/WebFetch 被策略拦截，但 shell 外网可用。本目录的 `web/` 子目录为 arXiv 官方 API 的真实检索结果（1,878 篇，最新 2026-10-30）；`*.json` 为早期基于内部知识的检索种子，保留用于交叉比对。两者冲突时，以 `web/` 中的 API 实测数据为准。
