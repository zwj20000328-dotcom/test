# 剧本格式标准规范 (Screenplay Format Standard)

> 本文件是**权威规范**。工作流的解析器 (`pipeline/parser.py`) 严格按本文识别 Markdown 剧本。
> **只要遵循"§2 标准模板"的写法，就不会出现解析错误。** 附录 §7 列出所有会导致解析异常的写法。
> 提交剧本前，请运行校验器：`python -m pipeline.validate your_script.md`（见 §6）。

---

## 1. 总览：Markdown 层级 → 剧本结构

解析器**只认标题层级 `#` / `##` / `###`** 来划分结构，其余靠固定标记识别。

| Markdown 写法 | 解析为 | 必需性 |
|---|---|---|
| `# 剧名` | 全剧标题 | 必需（全文件仅 1 个） |
| `## 角色表` | 角色档案区（不产生成片，只登记角色外形） | 强烈建议 |
| `## 第X集 …` | 一集 (Episode) = 一段成片 | 可选（不写则自动切分，见 §5） |
| `### 场景 …` | 一个场景 (Scene) = 同一时空 | 必需（至少 1 个） |
| `> 说话人：台词` | 一句对白/旁白 (Line) | 必需（场景内至少 1 句或 1 个动作） |
| `**字段**：值` | 该镜头/场景的属性（镜头、情绪、动作、音效等） | 可选 |

**铁律：**
- 一级标题 `#` 只能有一个，必须是剧名，放在最前（front-matter 之后）。
- 场景必须用 `###`（三个井号）。`##` 是"集"，`####` 及更深**不被识别**。
- 对白必须用 `>`（Markdown 引用块）开头。**普通正文里的对话不会被当作台词**。

---

## 2. 标准模板（照抄即用）

```markdown
---
title: 剧名
genre: 都市 / 甜宠
style: 写实电影感，暖色调
aspect_ratio: "9:16"
language: zh
target_episodes: 24
episode_seconds: 9
---

# 剧名

> 一句话故事：……（logline，可选）

## 角色表

- **林晚**：女，28岁。长直黑发，鹅蛋脸，杏眼，白色职业装，颈间银色细项链。
- **顾沉**：男，32岁。利落短碎发，剑眉星目，深黑高定西装，左腕铂金腕表。

## 第一集 · 契约

### 场景 1：民政局门口 · 白天 · 外

**人物**：林晚（白衬衫，紧张），顾沉（黑西装，冷峻）
**环境**：灰白民政局大楼，正午阳光刺眼
**氛围**：紧张、命运感
**镜头**：远景俯拍，两人在台阶上对立而站。
**动作**：林晚深吸一口气，攥紧户口本。
> 林晚（内心OS）：只要领了这本证，妈妈的手术费就有了。
**镜头**：中景，顾沉递来一支笔。
> 顾沉（冷淡）：想清楚了？签了，就没有回头路。
> 林晚（倔强）：我签。
**音效**：城市车流声、远处蝉鸣
**转场**：闪白
```

## 3. front-matter 字段（文件最顶部，`---` 包裹）

全部可选；缺省用默认值。**注意：`aspect_ratio` 的值要用引号包裹**（`"9:16"`），
否则 YAML 会把 `9:16` 当成六十进制数字解析成 `556`。

| 字段 | 含义 | 默认 | 合法值 |
|---|---|---|---|
| `title` | 剧名 | 取首个 `#` 标题 | 任意字符串 |
| `genre` | 题材 | — | 任意，用于 BGM 基调 |
| `style` | 全局画风 | 写实电影感 | 任意，映射到图像 prompt 前缀 |
| `aspect_ratio` | 画幅 | `"9:16"` | `"9:16"` / `"16:9"` / `"1:1"`（**加引号**） |
| `language` | 对白语言 | `zh` | `zh` / `en` |
| `target_episodes` | 期望集数 | 自动 | 整数 20–50（自动切分时生效） |
| `episode_seconds` | 每集目标秒数 | `9` | 数字，6–15 |

---

## 4. 场景内字段标记（`**字段**：值`）

在 `###` 场景块内，用**加粗字段名 + 冒号**标注属性。冒号中英文均可（`：` 或 `:`）。
下表是解析器**认识的全部字段**；未列出的字段会被收进 `scene.extra`（不报错，但也不参与生成）。

| 标记 | 作用 | 归属 | 缺省行为 |
|---|---|---|---|
| `**人物**：` | 出场角色（**首次出场请写外形**，用于角色一致性） | 场景 | 从对白说话人推断 |
| `**环境**：` | 场景视觉描述 | 场景 | LLM 从上下文生成 |
| `**氛围**：` / `**情绪**：` | 情绪基调（驱动 BGM + 表演 + 调色） | 场景 | 中性 |
| `**镜头**：` | 镜头语言（景别/机位/运镜）——**每写一次开启一个新分镜** | 镜头 | 自动分配景别 |
| `**动作**：` | 角色动作（驱动视频运动 prompt） | 镜头 | 从对白推断 |
| `**音效**：` / `**SFX**：` | 音效，用 `、` 或 `/` 分隔多个 | 镜头 | 自动补环境音 |
| `**转场**：` | 转场（切/淡入淡出/闪白/淡出） | 镜头 | 硬切 |
| `**BGM**：` / `**配乐**：` | 指定配乐 | 场景 | 按 `氛围` 自动选 |

> **分镜规则**：`**镜头**：` 是分镜边界。一个 `**镜头**` 到下一个 `**镜头**` 之间的
> 对白/动作/音效，属于同一个镜头（会生成同一张关键帧 + 同一段视频）。
> 一个镜头建议 1–3 句对白、时长 3–8 秒。

---

## 5. 对白行（`>` 引用块）

格式：`> 说话人（括注）：台词内容`

- **说话人**：角色名，需与"角色表"或 `**人物**` 中的名字一致。
- **括注**（可选）：情绪 或 声道类型，写在 `（）` 或 `()` 里。
  - 情绪：`（愤怒）`、`（哽咽）`、`（温柔）` —— 传给 TTS 控制语气。
  - 声道类型：`内心OS`、`画外音`/`VO`、`旁白`、`字幕` —— 决定字幕样式与配音方式。
  - 可组合：`（内心OS，紧张）` → 声道=OS，情绪=紧张。
- **特殊说话人**：`旁白`、`画外音`、`内心OS`、`字幕`（不写具体角色名也可）。

示例：
```markdown
> 顾沉（冷淡）：想清楚了？          # 普通对白，情绪=冷淡
> 林晚（内心OS）：我别无选择。       # 内心独白，字幕用斜体浅蓝样式
> 旁白：三年后。                    # 旁白
> 林晚（哽咽，强笑）：妈，钱解决了。  # 情绪=哽咽，强笑
```

**一句一行**；长台词请按句拆成多个 `>` 行（每行是一个 TTS 片段 + 一条字幕）。

---

## 6. 集切分：两种模式

- **模式 A（显式分集，推荐）**：用 `## 第X集` 自己切好每一集。控制力最强。
- **模式 B（只写场景）**：不写任何 `## 集`，只写 `### 场景`。解析器把场景收进
  `loose_scenes`，由 Stage 2 (LLM) 按 `target_episodes` / `episode_seconds` 自动聚合成集。

两种模式可混用，但**同一剧本建议统一**，避免歧义。

## 7. 提交前校验

运行校验器（会在解析前抓出格式问题，给出**行号 + 修复建议**）：

```bash
python -m pipeline.validate examples/sample_screenplay.md
```

- 退出码 `0` = 通过，可安全进入流水线；`1` = 有 error（必须修）；warning 可忽略。
- 校验项见 `pipeline/validate.py`：标题层级、唯一剧名、对白格式、角色一致性、
  aspect_ratio 引号、空场景、集时长越界等。

## 8. 附录：会导致解析错误 / 降质的写法

| ❌ 错误写法 | 后果 | ✅ 正确写法 |
|---|---|---|
| 用 `####` 或更深标题写场景 | 场景不被识别 | 场景一律 `###` |
| 台词不用 `>`，直接写正文 | 台词丢失（当作镜头描述） | 台词一律 `> 说话人：台词` |
| `aspect_ratio: 9:16`（无引号） | 被解析成整数 `556` | `aspect_ratio: "9:16"` |
| 写多个 `#` 一级标题 | 剧名被覆盖/结构错乱 | 全文件只 1 个 `#` |
| `**镜头**` 与台词距离过远、中间夹大段正文 | 分镜归属混乱 | 一个 `**镜头**` 紧跟其台词/动作 |
| 角色名前后不一致（"林晚" vs "林小姐"） | 角色一致性锚定失败、TTS 音色错配 | 全剧角色名严格统一，与角色表一致 |
| 首次出场不写外形 | 无法建立角色定妆档案，长相随机漂移 | `**人物**` 或角色表里写清外形 |
| 场景标题不含 `地点 · 时间 · 内外` | location/time 可能识别不全（不报错，降质） | `### 场景 1：咖啡厅 · 白天 · 内` |
| 用中文全角空格缩进字段 | 个别字段可能不匹配 | 字段名紧贴 `**`，冒号后用普通空格 |
| 一行塞多个说话人的台词 | 只解析出第一个说话人 | 一句台词一行 `>` |

## 9. 解析产物（内部契约，非用户输入）

解析器输出 `script.raw.json`（Stage 1 产物），后续每个阶段**读取并回填**它：

```jsonc
{
  "title": "闪婚之后满级大佬",
  "meta": { "genre": "...", "style": "...", "aspect_ratio": "9:16", "language": "zh" },
  "logline": "为凑母亲手术费……",
  "characters": [
    { "id": "x001", "name": "林晚", "gender": "女", "age": 28,
      "appearance": "长直黑发，鹅蛋脸……银色细项链",
      "voice_id": null, "ref_images": [] }        // ← 定妆/TTS 阶段回填
  ],
  "episodes": [
    { "ep": 1, "heading": "第一集 · 契约", "target_seconds": 9,
      "scenes": [
        { "id": "s001", "heading": "场景 1：民政局门口 · 白天 · 外",
          "location": "民政局门口", "time": "白天", "int_ext": "外",
          "mood": "紧张、命运感", "environment": "灰白民政局大楼……",
          "characters": ["林晚（白衬衫，紧张）", "顾沉（黑西装，冷峻）"],
          "shots": [
            { "id": "s001_sh002", "camera": "远景俯拍……", "action": "林晚深吸一口气……",
              "sfx": ["城市车流声", "远处蝉鸣"], "transition": "闪白",
              "lines": [ { "speaker": "林晚", "emotion": null, "kind": "os",
                           "text": "只要领了这本证，妈妈的手术费就有了。" } ],
              "visual_prompt": null, "motion_prompt": null, "est_seconds": null }  // ← Stage 2 回填
          ]
        }
      ]
    }
  ],
  "loose_scenes": [],   // 模式 B 时场景先落这里
  "_stats": { "episodes": 3, "scenes": 6, "shots": 11, "dialogue_lines": 21, "characters": 5 }
}
```

各阶段回填字段：`visual_prompt`/`motion_prompt`/`est_seconds`（Stage 2 LLM）→
`ref_images`（Stage 3 定妆）→ `keyframe_path`（Stage 4）→ `clip_path`（Stage 5 视频）→
`audio_path`/`word_timestamps`/`voice_id`（Stage 6 TTS）→ `srt_path`/`ass_path`（Stage 7 字幕）→
`bgm_path`（Stage 8）→ `episode_path`（Stage 9 装配）→ `final_path`（Stage 10 拼接）。
这份 JSON 同时是**断点续跑 (resume)** 的状态载体。
