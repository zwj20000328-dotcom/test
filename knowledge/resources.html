新增一篇教程

  1. 在 content/graph.js 的 topics 数组登记 slug、标题、层级、标签与前置条目。
  2. 新建 content/aiinfra/<slug>.js，按 window.KB_CONTENT["<slug>"] = { ... html } 的结构写正文。
  3. 运行 npm run build：自动合并摘要、要点、阅读时长，输出 assets/js/data.js，并校验图数、字数与 HTML 禁忌。
  4. 运行 npm run serve 本地预览，或直接双击 index.html（纯静态，file:// 也能跑）。
npm run build
npm run serve

校验会检查：每篇至少 3 个 SVG、正文不少于 3000 字、不得包含脚本标签、正文中不得出现模板字符串的反引号或美元花括号序列。

本地运行

不需要构建工具或依赖。推荐用本地服务器打开，避免个别浏览器对 file:// 的脚本限制。

npm run serve
